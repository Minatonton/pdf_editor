# Adobe Acrobat の編集機能との対応表

Acrobat の「PDF を編集」「コメント」「入力と署名」「ページを整理」「墨消し」にある機能を、このアプリでどう実現するかの一覧。
機能を足すたびに状態を更新する。

状態: ✅ できる / 🚧 これから作る / ― 作らない

## PDF を編集

| Acrobat の機能 | 状態 | このアプリでのやり方 |
|---|---|---|
| テキストを追加 | ✅ | ページをクリックして直接打つ。大きさ・色は選んだ文字のすぐ上で変える |
| 画像を追加 | ✅ | 置く場所をクリック。角を引いて大きさを変える |
| 元の文字を編集 | 🚧 | pdf.js で読み取った文字の行をクリックすると、その行を白塗りで隠し、同じ位置・大きさのテキストとして打ち直せる |
| リンクを追加 | 🚧 | 範囲を描いて URL かページ番号を指定する |
| 透かし | 🚧 | 文字を斜めに薄く、全ページに重ねる |
| ヘッダー・フッター、ページ番号 | 🚧 | 全ページの上下に文字やページ番号を入れる |
| ページのトリミング | 🚧 | 表示範囲（CropBox）を変える |
| 元の画像の移動・差し替え | ― | 画像がページの描画命令に埋もれていて、安全に取り出して並べ直す手段がない。白塗りで隠して新しい画像を置く形で代える |

## コメント

| Acrobat の機能 | 状態 | このアプリでのやり方 |
|---|---|---|
| ハイライト・下線・取り消し線 | 🚧 | 元の文字を選んで引く |
| 付箋（ノート） | 🚧 | PDF の注釈として保存し、ほかのビューアーでも開ける |
| 図形（四角・楕円・線・矢印） | ✅ | ドラッグで描く |
| 手書き（フリーハンド） | ✅ | ペンで描く |
| マーカー（範囲） | ✅ | 半透明の四角を重ねる |

## 入力と署名

| Acrobat の機能 | 状態 | このアプリでのやり方 |
|---|---|---|
| フォームの欄に入力 | 🚧 | PDF のフォームの欄の上に入力欄を出し、保存で欄に書き込む |
| ✓・✗・○・日付 | ✅ | スタンプとして置く |
| 署名 | ✅ | 手書きで描くか、名前を打って作り、画像として置く。作った署名はどこにも保存しない |
| 印鑑 | ✅ | 名前から朱色の丸印を作る |
| 白塗り | ✅ | 範囲をドラッグして白い四角を重ねる |

## ページを整理

| Acrobat の機能 | 状態 | このアプリでのやり方 |
|---|---|---|
| ページの一覧・移動 | ✅ | 左にサムネイルを並べる |
| 回転・削除 | ✅ | サムネイルを複数選んでまとめて行う |
| 並べ替え | ✅ | サムネイルをドラッグする |
| 空白ページの挿入 | ✅ | 選んだページの後ろに、直前のページと同じ大きさで足す |
| ファイルを結合・ページを挿入 | ✅ | 「追加」か、画面に PDF を落として、選んだページの後ろか末尾に足す |
| ページの抽出・分割 | ✅ | 選んだページだけを別の PDF として保存する。選ばなかったページの中身はファイルに残らない |

## 墨消し

| Acrobat の機能 | 状態 | このアプリでのやり方 |
|---|---|---|
| 墨消し | ✅ | 範囲を黒く塗ったうえで、そのページを画像にして元の文字を消す。上に黒い四角を重ねるだけでは、下の文字がコピーや検索で読めてしまうため |

## 作らないもの

| Acrobat の機能 | 理由 |
|---|---|
| パスワードによる保護 | 使っている pdf-lib が暗号化に対応しておらず、ブラウザの中だけで安全に実装する手段がない |
| OCR、Word・Excel への変換、比較、圧縮 | 「PDF の上に書き込んで保存する」という目的から外れ、ブラウザの中だけでは品質を保てない |

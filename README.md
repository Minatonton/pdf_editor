# PDF Editor

PDF の上にテキストや画像を置いて、新しい PDF として保存するローカル Web アプリ。個人利用を前提にしている。

ファイルはすべてブラウザの中で処理し、どこにも送信しない。

## 起動

Node.js（pnpm）が必要。

```sh
pnpm install
pnpm dev      # http://localhost:5173
```

テスト:

```sh
pnpm test
```

## 現在できること

| 操作 | やり方 |
|---|---|
| PDF を開く | 「PDF を開く」で選ぶか、画面にドロップする |
| テキストを置く | 「テキスト」を押してページをクリックし、右のパネルで内容・サイズ・色を変える |
| 画像を置く | 「画像」で選ぶか画面にドロップし、ページの置きたい場所をクリックする（PNG / JPEG 以外は PNG に変換する） |
| 動かす・大きさを変える | ドラッグで動かす。画像は右下の角で大きさを変える（縦横比は保つ）。矢印キーで 1pt、Shift と一緒に 10pt ずつ動かせる |
| 消す | 選んで Delete、または右のパネルの「削除」 |
| 元に戻す / やり直す | ⌘Z / ⌘⇧Z |
| 保存 | 「PDF を保存」で `元の名前_edited.pdf` をダウンロードする |

回転しているページ（/Rotate 付き）にも、画面で見えている向きのまま置ける。

> [!NOTE]
> テキストは画像として埋め込む。日本語をそのまま表示できる一方で、保存した PDF の中では文字として選択・検索できない。
> 理由は `src/annotations/textRaster.ts` のコメントを参照。

## 構成

| パス | 役割 |
|---|---|
| `src/pdf/` | PDF の読み込み（pdf.js）と書き出し（pdf-lib）、画面とページの座標の変換 |
| `src/annotations/` | 置いたテキスト・画像のデータと、元に戻す・やり直すの履歴 |
| `src/components/` | React コンポーネント |

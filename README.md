# PDF Editor

PDF に書き込み・ページの整理・墨消しなどをして、新しい PDF として保存するローカル Web アプリ。
Adobe Acrobat の編集機能をそろえることを目標にしている（対応表: [docs/ACROBAT_PARITY.md](docs/ACROBAT_PARITY.md)）。

ファイルはすべてブラウザの中で処理し、どこにも送信しない。

## 起動

Node.js（pnpm）が必要。

```sh
pnpm install
pnpm dev      # http://localhost:5173
```

テスト:

```sh
pnpm test
```

## できること

| 分類 | できること |
|---|---|
| 編集 | 元の文字の書き換え、テキスト・画像の配置、URL やページへのリンク |
| コメント | 付箋、ハイライト・下線・取り消し線、図形（四角・楕円・線・矢印）、ペン、マーカー |
| 入力と署名 | PDF のフォームの欄への入力、✓・✗・○・日付のスタンプ、手書き・名前の署名、名前から作る印鑑、画像の白を透明にする |
| 全ページ | 透かし、ヘッダー・フッター（ページ番号） |
| ページの整理 | 回転・削除・並べ替え・白紙の挿入・別の PDF の追加・抜き出し・トリミング（複数ページまとめて） |
| 隠す・消す | 白塗り（見た目だけ）、墨消し（中身ごと消す） |

### 画面

| 場所 | あるもの |
|---|---|
| 左のパネル | すべてのツール（PDF を編集・コメント・入力と署名・ページを整理・隠す・墨消し）。左上のボタンでアイコンだけの帯に畳める |
| 書類の左上 | よく使う道具（選択・付箋・ハイライト・ペン・テキスト・署名） |
| 書類の上 | 持っている道具の名前とやり方、「完了」 |
| 書類の下 | ページの移動と表示倍率 |
| 右のパネル | ページの一覧と、回転・削除・白紙・追加・抜き出し・トリミング。右端の帯で開け閉めする |

### 操作

| 操作 | やり方 |
|---|---|
| 置いたものを動かす・大きさを変える | ドラッグ。右下の角で大きさ（文字は文字の大きさ）を変える。矢印キーで 1pt、Shift と一緒に 10pt |
| テキストを書き直す | ダブルクリック、または選んで Enter |
| 写す・貼る・複製 | ⌘C / ⌘V / ⌘D |
| 消す | Delete |
| 元に戻す / やり直す | ⌘Z / ⌘⇧Z |
| 拡大・縮小 | ⌘＋ / ⌘− / ⌘0、トラックパッドのピンチ、「幅に合わせる」 |
| 道具をやめる | Esc |

> [!NOTE]
> - 置いたテキストは画像として埋め込むので、保存した PDF の中では選択・検索できない（理由は `src/annotations/textRaster.ts`）。
> - 白塗りは見た目を隠すだけで、下の文字はコピーや検索で読める。中身ごと消すには墨消しを使う。墨消ししたページは画像になる。
> - ページを削除・抜き出したときは、使わないページの中身をファイルに残さない。そのとき、しおりや文書全体のフォームは引き継がれない。

## 構成

| パス | 役割 |
|---|---|
| `src/editor/` | 編集中の文書（ページの並び・置いたもの・フォームの値・透かし）と、元に戻す・やり直すの履歴 |
| `src/annotations/` | 置くものの種類、図形のパス、文字や署名・印鑑の画像化 |
| `src/pdf/` | PDF の読み込み（pdf.js）と保存（pdf-lib）、座標の変換、使わないページの中身の除去、墨消し |
| `src/components/` | React コンポーネント |
| `docs/` | レビューから取り入れたこと、Acrobat との対応表 |
